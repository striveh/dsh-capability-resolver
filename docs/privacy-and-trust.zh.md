# 隐私与信任

[English](privacy-and-trust.md)

能力发现会把本地用户文本与不可信公开元数据结合。本页区分哪些数据会离开 Host、哪些数据可能在 DSH 其他位置持久化，以及候选结果不能证明什么。

## 外部请求

内置 provider 只向 `https://awesome-dsh-plugin.com/plugins.json` 发出一次有界 HTTPS GET。并发观测共享一个正在执行的 GET；单个观测者取消不会泄露需求文本，也不会在仍有其他观测者等待时启动额外请求。目的地址固定在源码中，不属于插件配置。请求不包含需求文本、session id、已配置模块名、工具名、Skill 名、Cookie、凭据、安装请求或搜索参数。

目录服务和普通网络基础设施仍可观察 Host 网络地址、请求时间、TLS/HTTP 元数据，以及该目录被下载这一事实。DNS、代理、终端安全或企业网络策略可能增加各自的观测能力。

## 本地需求处理

Host 在本地裁剪、限制、规范化和排序需求文本。解析器只缓存目录，不建立需求历史数据库。浏览器页面可以在普通页面内存中保存当前表单与结果。

Agent 调用 `capability_resolve` 时，需求文本仍遵循 DSH 正常的模型请求与会话日志行为。工具不会把浏览器 RPC 的完整结果交给模型，而是先生成独立的安全投影；DSH 正常日志只记录该投影后的工具结果。本插件不会绕过、清理或删除 DSH 所属的记录。用户仅在 UI 页面直接查询，不会因此让结果对模型可见。

UI 通过固定 Connection RPC channel 调用 Host，且该 channel 仅允许 loopback。相同用户下的本地进程、浏览器扩展、屏幕录制、已受控的 Host 或浏览器仍可能观察该用户可见的数据。Loopback 是访问限制，不是针对本地账户的隔离边界。

## 目录保留

Host 只在内存中保留有界的最近一次成功规范化目录。新鲜与过期上限决定是否复用。插件释放会清空缓存、中止共享请求并等待该请求结束。插件重新加载、禁用、卸载或 DSH 进程退出后，缓存状态消失。本插件不会把目录或需求数据写入自己的磁盘文件或浏览器持久化存储。

## 不可信元数据

每条目录记录都不可信。名称、描述、分类、仓库链接、热度数字、日期和包名可能错误、过期、被操纵或含有恶意内容。解析与 URL/包名限制可以降低注入和命令拼接风险，但不会检查仓库代码，也不能证明维护者身份。

DSH `0.1.1-rc.2` 没有一个标准工具结果标注，可以在模型序列化和会话重放阶段把文本块标为不可信。该版本的工具运行时会向 Code Mode 提供 canonical value，并根据该值渲染内容。直接调用会把渲染结果发送给模型并写入 `tool/result`；Code Mode 内部调用会把渲染结果写入 `tool/code-dispatch`。因此，本解析器不依赖文字警告或不存在的污点标记。模型可见 canonical value 与渲染结果只保留有界白名单：固定 provider/目录身份、再次严格校验的仓库与目录详情 URL、可选且严格解析的 npm 包标识符、匹配字段枚举、非负数值/日期事实、当前匹配数量与类型、目录完整性/旧缓存/无效记录数量，以及明确的隐私与只读标志。

目录名称、描述、分类标签、匹配词、警告文本、已配置模块标识符，以及当前工具/Skill 名称与描述只保留在经过深度校验的 loopback UI 响应中。它们不会进入模型可见 canonical value，也不会进入该工具面向会话日志的渲染结果。如果投影时某个候选不再具有严格仓库身份，该候选会被丢弃；若 `consider-plugin` 的候选全部被丢弃，模型结果会降为 `unavailable`。

以下信息只属于发现证据：

- 本地词法匹配；
- 被目录或 GitHub topic 收录；
- 目录详情页与仓库链接；
- star、下载量或收录日期；
- 结构化 npm 包名。

它们都不能证明 DSH 兼容性、包完整性、安全性、维护质量、法律适用性或 DeepSeek 背书。

## 无安装权限

本插件不会调用 `dsh plugin add`、包管理器、shell、子进程 API 或安装器，也不会启用、禁用、更新或移除其他插件。结构化 `installSpec` 只是供人检查的一个值，不代表授权，也永远不会被执行。

安装候选前，应检查精确源码版本、package manifest、生命周期脚本、依赖、权限、所需凭据、DSH 版本支持、发布证据与移除行为。优先选择固定 tag 或 commit，并在隔离 profile 中做验收。

## 可报告的安全问题

有价值的私密报告包括：需求文本离开 Host、任意目录目的地址、重定向绕过固定来源、无界输入或保留、跨源 RPC 访问、命令拼接或执行、不安全链接渲染、原始恶意目录数据泄漏到日志，或 package 产物与源码不一致。请遵循 [`SECURITY.md`](../SECURITY.md)，并使用合成数据。
